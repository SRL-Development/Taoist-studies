# 本地书库与原图修复

## 奇门底本

采用用户指定的1925年文明书局《奇门遁甲统宗》：秦慎安校勘，国家图书馆藏，4册十二卷，全408页。
来源：https://commons.wikimedia.org/wiki/File:NLC416-12jh003951-48665_奇門遁甲統宗.pdf
来源说明标注公有领域机械扫描。原始 PDF 保存于 dist/books/qimen-tongzong-1925.pdf，原页经 Poppler 栅格化为本地 JPG。
未重新绘制图形。第33页为九星直符图、八门直使图；第35—36页为神咒及相关文字；第45页为排布方法；第51页为日奇布五符法文字。图式、神咒和文字条目分别标识，不称为统一的佩带符。

## 文字书库

来源为公开古籍转录镜像，URL 随各书 JSON 保存。古籍原作与古注依原作年代作为公有领域材料整理；不提供现代白话译本。转录仍可能包含错字、缺文与未识别图表，不宣称逐字校勘或底本完整。

- ytzeng1/fengshui_data：梅花易数、增删卜易、卜筮正宗、三命通会、渊海子平、六壬直指御定、太乙金镜式经、钦定协纪辨方书。
- daizhige-org/daizhigev20（data分支）：周易正义、滴天髓阐微、紫微斗数（万历续道藏录入本）。
- 周易入口实际提供《周易正义》，滴天髓入口提供含任铁樵注的《滴天髓阐微》。紫微入口目前仅收道藏《紫微斗数》，不是原先列出的《紫微斗数全书》版本，阅读器明确标示。
- 分段用于阅读性能，不冒称原书卷界。所有正文随 Docker 发布，访问时不请求 GitHub 或维基文库。

scripts/import-classics.mjs 为较早的维基文库导入尝试，遇到来源限流后停止，未将缺失页宣称为全文。当前成品由 import-text-mirror.mjs 与 complete-library.mjs 生成。不要在发布构建中自动抓取网络资料，部署使用已提交的本地文件。
