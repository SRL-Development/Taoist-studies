# 微信小程序适配计划

当前交付为 Docker 网站，不包含可提交微信审核的原生小程序包。

## 两条路线

| 路线 | 复用内容 | 待开发 |
| --- | --- | --- |
| H5 嵌入 | 网站页面及 Docker 服务 | HTTPS、业务域名配置、平台资格核验、真机测试和审核 |
| 原生小程序 | 排盘算法、术数资料与勘察模板 | 原生页面、存储、图片选择、画布分析、报告输出 |

微信平台资格、web-view、域名及审核要求应在实际开发时核对官方最新文档，本说明不承诺当前主体可直接使用 web-view。

## 推荐实施顺序

1. 将 Docker 网站部署到自己的 HTTPS 域名，跑通移动端流程。
2. 从 `src/tools-pro.js` 拆出不依赖 DOM 的排盘计算和像素分析纯函数，网页与小程序分别渲染。
3. 将 `dist/talisman-catalog.js`、`dist/folk.js`、`dist/platform.js` 的资料提取为固定 ID 的 JSON，统一图版、来源与模板数据。
4. 原生实现排盘、图鉴、勘察三条流程，以微信存储接口替换 localStorage。
5. 使用小程序图片选择与画布 API 重写照片初筛；浏览器 Blob 下载、dialog、打印不能直接照搬。
6. 如需跨设备同步，再加入独立账号、API 与数据库。当前 Docker 网站没有服务端账号和同步接口。

独立站与后续小程序均无需依赖 ChatGPT 登录。若加入用户系统，应采用平台自身身份体系。
